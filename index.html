DVReader Pro

A mobile-first, production-grade PDF reader, annotator, and rich text editor built with pure HTML, CSS and Vanilla JavaScript — no frameworks, no server.

About the Developer

Rev. Dr. Chris Johnson is the founder and president of CEMLCA (Christian Education and Ministry Leadership Community Association) and the creator of Biblefirm — a ministry technology brand dedicated to reaching six million souls across six continents through digital tools.

DVReader Pro is part of the Biblefirm suite of Kingdom-focused progressive web applications, built to serve students, ministry leaders, and researchers worldwide.

Features

  • Virtual DOM rendering — only visible pages loaded (memory-safe)
  • Decoupled session save — annotations stored separately from PDF
  • Freehand drawing, highlights, sticky notes, text boxes
  • Rich text editor with word, character, and page counters
  • Save session (.dvr), export PNG, print-to-PDF
  • Installable PWA — works offline after first load
  • Full accessibility labels (ARIA)
  • Light and dark mode with PDF.js branding

Technology

Pure HTML5 + CSS3 + Vanilla JavaScript. Single file. No CDN dependency, no frameworks, no emoji. Android-first Material Design 3 layout. Roboto and Inter system fonts. PDF.js rendering engine.
